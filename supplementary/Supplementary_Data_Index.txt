Version note (v4, diversity re-run with all 22 samples):
- S4, S5, S6, S7 were recalculated for all 22 samples (11 IBD, 11 healthy) from the species-level Bracken files (fraction_total_reads; Shannon index in natural log). Sample 20 was previously omitted because its Bracken file was saved as .xlsx rather than .csv. The 21 previously reported Shannon and Simpson values were reproduced.
- S5 rows and columns are now in numeric sample order (1-22). In the previous version the matrix values were in numeric order but labelled in text-sorted order (10, 11, ..., 1, 21, 22, 2, ...), and the S6 group labels were assigned in the same wrong order; the previous PERMANOVA (pseudo-F = 1.754, p = 0.091) was therefore based on mismatched labels.
- S7: PERMANOVA with 9999 permutations (previously 999).

Version note (v8, genus taxonomy re-assigned; genus-level results regenerated):
- Reason: for nine IBD samples (2, 3, 4, 5, 7, 8, 9, 10, 11) the ASVs are in reverse orientation, so no genus had been assigned to them in S3 (0% genus-level assignment for these samples). Taxonomy was re-assigned with the SILVA 138.2 training set (silva_nr99_v138.2_toGenus_trainset, naive Bayesian classifier, 8-mers, 100 bootstraps, minBoot 50), trying both strands (tryRC). Genus is now assigned to 61% of ASVs (previously 39%). Of the 892 ASVs that had a genus before, 874 keep the identical genus, 18 are now unassigned and none changed genus.
- S3: replaced by the re-assigned taxonomy (2,266 ASVs).
- S10, S11: DESeq2 (R; poscounts size factors, Wald test, IBD vs healthy, genera with >= 10 reads, "Unclassified" excluded) re-run on the corrected genus table: 186 genera tested, 44 with padj < 0.05 (12 higher, 32 lower in IBD). 27 of the 44 are absent from one of the two groups, so their log2 fold changes and p-values are very large and should be read as presence/absence differences. Genera detected in a single sample are replaced by DESeq2's outlier handling and have baseMean 0 / padj NA.
- S12-S14, S20, S24-S28, S27b: recalculated from the corrected genus table (Spearman correlation with the per-million pathway table S8b, Benjamini-Hochberg FDR within each pathway, genera present in >= 2 samples). 84 significant genus-pathway correlations (S12); 51 of these involve DESeq2-significant genera (S13, S25); biomarker-focused network: 32 nodes, 51 edges (S27); broader network: 55 nodes, 84 edges (S27b).
- S24: Paludicola is no longer DESeq2-significant (padj = 0.19) and is now low priority in S20; the five-genus panel is otherwise unchanged. S15-S19, S21-S23 and S29-S31 are based on the Bracken genus abundances (S2) and are unchanged.
- S2, S4-S9 and S32 are unchanged.
